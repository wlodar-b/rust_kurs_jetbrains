## Widok kursu

<b>Widok kursu</b> pokazuje program kursu: listę lekcji z zadaniami.

<style>
img {
  display: block;
  margin-left: auto;
  margin-right: auto;
}
</style>
<img src="edu_course_view.png" class="center" width="75%"/>

Możesz przejść do dowolnego zadania, klikając dwukrotnie jego nazwę.

Aby ukryć okno Widoku kursu, kliknij przycisk Okno narzędzi projektu lub naciśnij <span style="color: #509DD6">&shortcut:ActivateProjectToolWindow;</span>. Dzięki temu zyskasz więcej miejsca na okna Edytora i Opisu zadania.

Aby przywrócić ukryte okno Widoku kursu, kliknij ponownie przycisk Okno narzędzi projektu (lub naciśnij <span style="color: #509DD6">&shortcut:ActivateProjectToolWindow;</span>).
