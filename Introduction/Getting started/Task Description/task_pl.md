## Opis zadania

Okno **Opis zadania** zawiera wszystkie informacje potrzebne do wykonania zadania:

Dla zadań teoretycznych opis zawiera materiały do nauki i do czytania.  
W przypadku quizów oferuje pytania wielokrotnego wyboru.  
Dla zadań programistycznych opis podaje problem do rozwiązania.

Używaj elementów okna Opis zadania do następujących działań:

| Element                                                          | Opis                                                                                                                    |
|------------------------------------------------------------------|-------------------------------------------------------------------------------------------------------------------------|
| **Check**                                                        | <font size="-1">Sprawdź poprawność swojej odpowiedzi (dla quizu) lub swojego rozwiązania kodu (dla zadania programistycznego)</font> |   
| **Run**                                                          | <font size="-1">Uruchom swój kod (dla zadań teoretycznych)</font>                                                      |
| ![](images/back.svg)                                             | <font size="-1">Przejdź do poprzedniego zadania</font>                                                                  |    
| ![](images/forward.svg) &nbsp;<font size="-1">lub</font> **Next**| <font size="-1">Przejdź do kolejnego zadania</font>                                                                     | 
| ![](images/reset.svg)                                            | <font size="-1">Cofnij wszystkie wprowadzone zmiany w zadaniu i zacznij od nowa</font>                                  | 
| ![](images/commentTask.svg)                                      | <font size="-1">Zostaw komentarz do konkretnego zadania</font>                                                          | 
| <a>Podejrzyj rozwiązanie...</a>                                  | <font size="-1">Pokaż poprawną odpowiedź i wyświetl <b>różnicę</b></font>                                              |

Zalecamy utrzymanie widoczności okna Opis zadania i unikanie całkowitego jego ukrywania. Jeśli jest zbyt rozpraszające, możesz je schować, klikając przycisk ![](images/hideToolWindow.svg) w prawym górnym rogu okna Opis zadania.

Jeśli używasz dwóch monitorów, pomocne może być przełączenie panelu Opis zadania w tryb pływający i przeniesienie go na drugi monitor lub umieszczenie go obok głównego okna IDE. Aby to zrobić, kliknij ikonę ustawień okna narzędziowego ![](images/gear.svg):
