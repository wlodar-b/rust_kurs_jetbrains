## Użyj `as`

Rzutowanie typów w Rust odbywa się za pomocą operatora `as`.  
Należy pamiętać, że operator `as` nie jest stosowany wyłącznie do rzutowania typów.  
Pomaga również przy zmianie nazw importów.

Celem jest upewnienie się, że dzielenie nie spowoduje błędu kompilacji  
i zwróci odpowiedni typ.

<div class="hint">Użyj operatora <code>as</code>, aby zrzuć jeden z operandów w ostatniej linii funkcji  
<code>average</code> na oczekiwany typ zwrotny.</div>
