## Utwórz tablicę

Utwórz tablicę z co najmniej 100 elementami. Uruchom plik main.rs, aby zobaczyć, jakie są wyniki Twojego kodu. Nie zmieniaj linii, które są zwracane &mdash; test sprawdza obecność tekstu `"Wow, that's a big array!"`.

<div class="hint">
  Istnieje skrócona metoda inicjalizacji tablic o określonym rozmiarze, która nie wymaga ręcznego wpisywania 100 elementów (ale możesz to zrobić, jeśli chcesz!).

  Na przykład możesz napisać:
  ```rust
  let array = ["Are we there yet?"; 10];
  ```
</div>

Bonus: jakie inne rzeczy mogłyby sprawić, że warunek `a.len() >= 100` byłby prawdziwy?
