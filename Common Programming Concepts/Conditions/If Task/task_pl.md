## Zwróć Większą Liczbę

Uzupełnij tę funkcję, aby zwracała większą liczbę!

Nie używaj:

* `return`
* wywołania innej funkcji
* dodatkowych zmiennych

<div class="hint">
  Możesz to zrobić w jednej linii, jeśli chcesz!

  Kilka podobnych przykładów z innych języków:
  - W C(++) byłoby to: `a > b ? a : b`
  - W Pythonie byłoby to: `a if a > b else b`
</div>
<div class="hint">
  Pamiętaj w Rust, że:

  * warunek <code>if</code> nie musi być otoczony nawiasami
  * warunki <code>if</code> / <code>else</code> są wyrażeniami
  * Każdy warunek kończy się blokiem <code>{}</code>.
</div>
